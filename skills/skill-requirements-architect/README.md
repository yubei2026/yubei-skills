# Skill 需求架构师

一个帮助普通用户从现实任务出发，调查、定义、创建和测试 Codex Skill 的 Skill。

它不会直接接受用户最初提出的职业名称或能力标签，也不会在信息不足时急着否定。它会先询问真实使用场景、输入材料和期望结果，再依据可靠的专业资料判断 Skill 应具备的能力。

## 它能做什么

- 引导用户说清现实任务，而不是要求用户先懂专业术语；
- 调查相关专业资料，区分事实、惯例、观点和推断；
- 判断用户提出的名称是否准确，并解释依据；
- 创建或修改 Skill 文件；
- 通过内部检查和新任务盲测验证真实行为；
- 根据现实任务的结果继续修改；
- 教用户维护 Skill，并在授权后协助更新 GitHub。

## 文件结构

```text
skill-requirements-architect/
├── SKILL.md
└── agents/
    └── openai.yaml
```

- `SKILL.md`：Skill 的核心目标、工作流程和规则。
- `agents/openai.yaml`：Codex 界面中的显示名称、简介和默认调用语句。

## 使用示例

```text
$skill-requirements-architect 我想制作一个导演 Skill，帮助我创作短视频。
```

Skill 会先了解你现实中准备提供什么材料、希望得到什么结果，再决定“导演”是否是准确的能力名称。

## 验收标准

这个 Skill 是否通过测试，不取决于回答格式是否漂亮，而取决于它创建的 Skill 能否完成用户的现实任务。
