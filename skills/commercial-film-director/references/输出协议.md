# 输出协议与项目状态

需要正式阶段产物或恢复项目状态时使用。根据任务删减，不输出空栏目。

## 项目状态

```markdown
### 项目状态
- 产品：
- 目标：
- 时长 / 画幅 / 渠道：
- 当前阶段：
- 已锁定：
- 待决定：
- 已否决及原因：
- 风险：
- 下一项决定：
```

记录决定，不要复述整段聊天。否决项必须附原因，避免之后换皮重提。

## 表达关卡

```markdown
### 品牌母题
<可反复成立的世界规律>

### 本片表达点
<具体、可观察的结论>

### 产品前 → 产品介入 → 完成状态
<三段式状态>

### 必须完成的任务或尖锐矛盾
<为什么人物不能暂停、离开或轻易规避>
```

## 结果发散

用紧凑表格提供机制不同的候选：

```markdown
| 完成状态 | 产品因果 | 画面钩子 | 生活入口 | 误导空间 | 风险 |
|---|---|---|---|---|---|
```

选定后记录胜出方案和理由。除非用户要求，不要为每个候选都写完整剧本。

## 因果与结构关卡

```markdown
### 一句话因果链
<完整因果>

### 观众假设
<可信的错误解释>

### 真实原因
<揭晓后的简单解释>

### 结构与信息顺序
<结构引擎、先给什么、延迟什么>

### 产品不可替代性
<删除或替换产品为何失败>
```

## 带时间码节拍表

```markdown
| 时间 | 事件 | 新增信息 | 观众判断 | 声音功能 |
|---|---|---|---|---|
```

每一行必须增加信息。两行承担同一任务时合并。

## 单镜头协议

```markdown
### 镜头 N｜时间｜叙事任务
- 画面与摄影机：
- 空间关系：
- 动作顺序：
- 可观察表演：
- 对白：
- 声音层与混音焦点：
- 连续性：
- 禁止项：
```

## 人物侧写协议

```markdown
### 人物 / 身份
- 叙事功能：
- 年龄与社会印象：
- 轮廓与体型：
- 五官与发型：
- 性格气质：
- 与其他角色的反差或般配：
- 服装与固定道具：
- 所需表演范围：
- 身份不变量：
```

## 资产提示词协议

```markdown
用途：
参考图角色：
主体：
身份 / 产品不变量：
构图或视图：
视觉语言属性：
灯光与空间：
准确文字：
必须保留：
禁止：
```

每张参考图必须标注为：编辑目标、身份参考、风格参考、场景参考、产品参考或合成素材。不能让风格参考悄悄变成身份或构图指令。

## 审查报告

先给结论：通过、返修当前阶段，或退回某个上游阶段。

```markdown
### 结论
<通过 / 返修当前阶段 / 退回阶段 N>

### 证据
- <时间码、画面、声音或可见细节>

### 被破坏的不变量或风险
- <具体问题>

### 下一轮修改
<只改变一个主要变量，同时列明要保留的内容>
```

准确文字、人物身份、空间连续性、产品状态或核心揭晓错误时，不能判定通过。
