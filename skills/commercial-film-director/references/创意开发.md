# 创意开发

本模块用于阶段 0–4：约束、母题与表达点、完成状态、因果引擎、结构、误导、递进和时间分配。

## 1. 建立真实简报

只收集会改变创意决定的信息：

- 产品和品类；
- 受众；
- 传播目标；
- 真实功能、消费时刻或品牌行为；
- 必须出现和禁止出现的内容；
- 允许的夸张程度和整体语气；
- 时长、画幅、投放渠道和制作方式。

独立创作时，不要虚构品牌方硬性要求。把母题和表达方向视为可选择变量。

## 2. 区分母题与表达点

**品牌母题**是可反复讲述的世界规律，例如饥饿改变人的状态、产品吸收能力极强、微小风险会连锁升级。

**表达点**是本片要证明的具体、可观察结论。它应包含：

- 产品前状态；
- 产品造成、阻止或解决的变化；
- 已经完成的产品后状态；
- 让变化产生意义的任务、关系或后果。

只有情绪、处境、功能词或口号的表达点不合格。把它转成摄影机能观察的变化或结果。

## 3. 先发散完成状态，再设计零散行为

完成状态是一个已经发生、足以支撑记忆画面、声音或揭晓的局面。根据结构，它可以发生在产品使用前或使用后。

发散时应生成机制不同的结果，不要只替换同一想法的地点和人物。主动改变：

- 场景和社会关系；
- 结果规模；
- 视觉或声音机制；
- 观众的错误解释；
- 产品是造成、阻止还是解决结果。

不能从“饥饿导致异常行为”直接跳到任意行为清单。先决定什么结果具有产品相关性、记忆度和可拍性。

用以下测试筛选：

- **删除产品测试**：产品消失后故事是否坍塌？
- **替换产品测试**：无关产品能否无损替换？
- **静音画面测试**：是否存在清楚的动作、形状或物理变化？
- **生活距离测试**：是否从观众熟悉的情境进入？
- **重解释测试**：揭晓能否解释此前线索？
- **递进测试**：压力或信息能否至少升级一次？
- **制作测试**：现有工具能否稳定表现？
- **记忆测试**：笑点之后还能否记住产品？

没有候选通过时，退回表达点，不要把弱结果写成长剧本。

## 4. 建立因果引擎

用一句话写完整因果链。第一次看应意外，回看时应简单。

优先使用熟悉的物件、职责、礼仪、时间压力、身体动作和社会假设。除非简报要求，避免加入复杂科技、奇幻规则或灾难片规模。

需要误导时，分别写明：

- **观众假设**：早期线索引导出的合理但错误解释；
- **真实原因**：后来出现、能用更少假设解释同一批线索的答案。

误导不是隐藏全部信息。应提供公平线索，只是让线索在揭晓后获得另一层意义。

## 5. 根据表达点选择结构

以下是可选引擎，不是固定模板。

### 产品直接造成结果

适合产品物理属性能产生强烈画面结果的情况。

常见逻辑：日常使用或意外 → 物理升级 → 不可能的完成结果 → 产品识别。

### 人物状态转换

适合食品、饮料、清洁、护理、能量、情绪或身份变化。

常见逻辑：不能中断的任务 → 异常状态妨碍任务 → 旁观者误读 → 产品介入 → 状态恢复或改变 → 完成任务。

### 连锁后果

适合风险、保险、防护和预防类产品。

常见逻辑：普通触发 → 多次可理解的连锁升级 → 不成比例的后果 → 防护或产品意义。

### 延迟原因

适合结果本身是最强钩子，且解释能够重写观众认知的情况。

常见逻辑：异常结果 → 多种可能解释 → 选择性线索 → 真正原因或产品。

### 顺叙递进、最后命名产品

适合事件发生过程本身就有喜剧性，打乱顺序反而降低清晰度的情况。

常见逻辑：日常入口 → 两到三次异常升级 → 最终结果 → 产品或广告语重新定义整段事件。

必须区分**编剧的推导顺序**和**观众得到信息的顺序**。用结果倒推得到的创意，仍然可以按时间顺序讲述。

## 6. 设计递进与时长

每次递进至少增加一项：

- 更大的后果；
- 更强的任务压力；
- 新的目击者或社会反应；
- 更具体的线索；
- 观众假设的变化；
- 逐渐清晰的视觉或声音母题。

没有新增信息的重复反应，不算递进。

30 秒广告可先按“一个入口、两至三次升级、一次揭晓、一次产品介入、一个收尾”估算，但不能把它当公式。当前后景、分屏或群像能承载同一节拍的信息时，优先合并重复切镜。

## 进入剧情前的关卡

确认以下内容后再写剧情：

- 一个表达点；
- 一个已选完成状态；
- 一句完整因果链；
- 结构与观众信息顺序；
- 错误解释与真实原因（如适用）；
- 带时间预算的节拍；
- 产品不能被无损替换的原因。
